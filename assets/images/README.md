# Assets Images Folder

Thư mục này chứa các tài nguyên hình ảnh cho ứng dụng chuyển đổi.

## Hình ảnh cần thiết:
- `avatar.png` - Ảnh đại diện hiển thị trên màn hình chính

## Hướng dẫn:
1. Thêm file `avatar.png` vào thư mục này
2. Kích thước đề xuất: 200x200 pixels
3. Định dạng: PNG hoặc JPG

Nếu không có file `avatar.png`, ứng dụng sẽ hiển thị icon mặc định.
